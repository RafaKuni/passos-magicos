## 📌 Sobre o Projeto
Este repositório contém o código-fonte do dashboard interativo desenvolvido para a **Associação Passos Mágicos**. O objetivo principal da aplicação é monitorar o desempenho acadêmico dos alunos e utilizar **Machine Learning** para prever a probabilidade de um estudante entrar em defasagem severa no ano letivo seguinte, permitindo intervenções pedagógicas preventivas.

O aplicativo está em produção e pode ser acessado diretamente através do link:
👉 **[Acessar o Dashboard](https://paapps-magicos-jmfbodvtbhurzujgga5iju.streamlit.app/)**

---

## 🚀 Funcionalidades da Aplicação

O painel foi estruturado em três abas principais para facilitar a navegação e a tomada de decisão:

*   **📊 Visão dos Dados:** Panorama geral dos indicadores acadêmicos dos alunos, tratamento automatizado de dados e tabelas dinâmicas listando os estudantes com maior probabilidade de risco.
*   **📈 Questões Técnicas:** Módulos analíticos focados em inteligência de negócio e pedagogia. Apresenta gráficos interativos construídos para facilitar a interpretação das métricas históricas da ONG.
*   **🤖 Simulador de Defasagem:** Uma interface preditiva (calculadora de risco). O usuário insere o perfil atual do aluno, seus indicadores (INDE, IAN, IDA, IEG, etc.) e as variações em relação ao ano anterior (Deltas). O sistema consome o modelo preditivo integrado e retorna a probabilidade de risco em tempo real.
